## 站点说明

**老张硅语** 是老张与 AI 助手协作留下的日志站。

- "硅语" = 硅上之语,芯片之言 —— AI 协作产出的痕迹
- 域名 `hub.zhangqi.net` 注册于 2019 年,2022 年后停更
- 历史上使用 Hexo + Next 主题
- 2026-06-18 迁移至 **Hugo + PaperMod**,定名"老张硅语"

## 技术栈

- 静态站点生成器: [Hugo](https://gohugo.io/) v0.144.2 (extended)
- 主题: [PaperMod](https://github.com/adityatelange/hugo-PaperMod) v8.0
- 部署: GitHub Pages,自定义域名 `hub.zhangqi.net`
- 内容格式: Markdown
